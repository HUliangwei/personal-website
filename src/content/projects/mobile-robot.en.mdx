## Architecture

Python / YOLO vision → ROS upper-controller task logic → upper/lower-controller communication → MCU lower controller → motor control → robot motion and the next task-loop state.

## Design / Method

YOLO provides visual recognition information; Python and ROS organize the upper-controller task flow. Communication carries commands to the MCU, where motor control produces physical action and advances the task loop.
