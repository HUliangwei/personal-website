## 项目概览

这是一个本科阶段移动机器人项目。公开且可支持的技术链路包括 Python、YOLO、ROS、上下位机通信、MCU、电机控制以及任务循环。本文不把该项目扩展到未被材料支持的其他平台。

## 问题 / 动机

项目目标是让视觉识别、上位机任务逻辑、下位机控制和电机执行形成闭环，使移动机器人能够按任务流程感知、决策并动作。

## 我的角色

现有材料支持项目参与和系统实现相关表述，但不足以分配未经记录的个人贡献比例。项目奖项仅作为**简历自述**：湖北省大学生电子设计竞赛二等奖；本次审计未获得证书，因此不标记为官方独立核验。

## 系统架构

Python / YOLO 视觉模块 → ROS 上位机任务逻辑 → 上下位机通信 → MCU 下位机 → 电机控制 → 机器人运动与下一轮任务状态。

## 设计 / 方法

使用 YOLO 提供视觉识别信息，由 Python 与 ROS 组织上位机任务流程；通过上下位机通信把控制指令交给 MCU，再由电机控制完成动作并推进任务循环。

## 实现

公开实现范围限定为 Python、YOLO、ROS、上下位机通信、MCU 与电机控制；现有材料没有支持更具体的软件版本、消息接口或个人模块归属，因此不作扩展。

简历自述该项目获得湖北省大学生电子设计竞赛二等奖。除此之外，不发布速度、识别准确率、任务成功率或其他未经材料核实的指标。

## 挑战与决策

系统难点在于跨越视觉、ROS 任务逻辑、上下位机通信和电机执行的接口。内容决策是严格使用当前简历支持的 ROS 移动机器人范围，不合并其他版本中的冲突描述。

## 收获与反思

项目提供了把感知算法、软件任务循环和嵌入式执行器连接为完整机器人系统的本科实践；未有材料支持的具体技术取舍不作推断。
